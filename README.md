#Kişisel CV Web sayfası

Bu proje html kullanılarak yapılmıştır. Basit bir CV web sayfasıdır.

#İçerik

Proje yabancı dil, mezun olunan lise, okumakta olduğu üniversite, hobiler ve ilgi alanlarından bahsetmektedir.

#Çalıştırma

Dosyayı indirdikten sonra herhangi bir tarayıcıda görüntüleyebilirsiniz.
